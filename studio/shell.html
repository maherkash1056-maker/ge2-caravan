        Class file through your n8n

        For networks that block Claude, such as the university network. Students' devices only talk to your n8n, and n8n talks to Claude. Your API key stays inside n8n, not in the file. About 10 minutes, once.

        1. In n8n, create a new workflow and use Import from File to open GE2-Claude-n8n-workflow.json.
        2. Open the step Ask Claude. Under Credential, create a new Header Auth credential: Name x-api-key, Value: your API key. Save it.
        3. Save the workflow and publish it (turn it on). Open the first step, Class file asks, and copy its Production URL.
        4. Paste the address below, press Test the address, then Download the class file. Send that file to your students.

        • The workflow also stops at about 300 Claude requests a day for the whole class. You can change that number at the top of its step Check the request.
        • Each exam is one n8n execution. Full 25-question papers take about a minute.

        Your class file (your API key inside)

        Students open the class file and make practice exams on your API credits: no Claude account and no class code. About 2 minutes.

        1. At platform.claude.com open API keys → Create key. Choose an expiry that lasts until the end of the term, then press Copy key.
        2. Paste it below and press Test the key.
        3. Choose a daily limit and press Download the class file. Open that file, make one quick exam, then send the file to your students.

        • Anyone who has the class file can find the key inside it, and whatever is done with the key counts as you. Send the file only to your class; never post it online.
        • If the file reaches the wrong people, delete the key at platform.claude.com → API keys. Every copy stops working at once; then make a new key and a new class file.
        • Spending stops at your monthly API credits. Each exam costs roughly 5–15 US cents.

        How it works

        Play and Make a game need no accounts: the games run inside this page. A team copies its game code and sends it to you; press Play → “A friend's game” and paste it. The result card shows the questions right, an English grade and a proof code.

        Practice exam and Check our questions ask Claude. Here on claude.ai each student uses their own Claude account (they must be signed in, and it uses their own allowance). The class file (made from the teacher file) and the class copy on Cloudflare run on your API credits instead, so students need no account.

        Practice exams follow the final-exam reading order: headings, True / False / Not Given, word box, A / B / C, one word or a number, table — plus listening (read aloud by the computer), grammar and vocabulary items for the skills students tick. Every reading answer is checked against the text before the game starts; questions that fail the check are removed.

        A 90-minute lab lesson

        5 minTeams of 2–3, one computer each. Open Make a game.
        15 minSteps 1–3: genre, look and the story in English.
        20 minStep 4: the text and at least 5 questions; “Check our questions with Claude” gives hints, not answers. Check every team before they play.
        15 minStep 5: play, fix, copy the game code and send it to you.
        10 minTeams swap computers and play each other's games; feedback with the frames.
        15 minStep 6: “How to play our game” — a short process text with the passive (writing LO4).
        10 minPractice exam: each student ticks their weakest skills and plays one short exam.

        Help

        Controls. Race: Space jumps. Penalty: Space or click shoots. Space shooter: arrow keys. Café: click the stations or press 1–4. Sweet match: drag sweets, or arrows + Space. Boss fight: arrows, Space, X, C. On phones, buttons appear on the screen.

        Saving. Work is saved on each computer while students type. “Start again” clears it for the next class.

        The class copy on your API credits

        For students without a Claude account. About 30 minutes, once. You need the file worker.js from Claude.

        1. In claude.ai open Settings → Billing → API credits and link a Console organization (your plan must be at least 7 days old). The credits arrive every month and expire at the end of the month.
        2. At platform.claude.com open API keys → Create key, and copy it. Paste it only into Cloudflare (step 5), never into a chat. Under Limits, keep auto-reload off so nothing is charged beyond the credits.
        3. Make a free account at dash.cloudflare.com. Open Workers & Pages → Create → start with “Hello World”, name it (for example ge2-games) and Deploy.
        4. Edit code → delete everything → paste all of worker.js → Deploy.
        5. Settings → Variables and Secrets → Add, type Secret: ANTHROPIC_API_KEY = your key. Add a second Secret: CLASS_CODE = a word for your class. Deploy.
        6. Open your new link (…workers.dev). The Practice exam tab says “Class copy”: type the class code and make one test exam.
        7. Give students the link and the code. Change the code each term. Each exam uses roughly 10–15 US cents of credits.
