If something goes wrong

“ID not on the list” → the ID is typed wrongly (letters and digits, no spaces) or the student is not in Group 9; add them later from the roster table.
Forgot PIN → Teacher tab ▸ class table ▸ Reset PIN on the row; the student sets a new one at the next login.
Page lags / nothing happens → one refresh. The session comes back by itself (it lives in the page address). If a phone is still stuck, the student logs in again — nothing is lost.
Campus Wi-Fi blocks the server (login hangs for everyone) → open your hotspot; the n8n link and the Royale server (workers.dev) both work on mobile data.
Royale: “No room with that code” → the code is 5 characters; students must be logged in on the Caravan page first and open Royale from the Play tab.
Claude is slow → 20–40 s per exam is normal when 25 students press at once; ask them to wait, not to press again.
